## General

<Accordions type="single">
  <Accordion title="I see multiple plugin variants such as Paper, Bukkit, and Velocity. Which one should I use?">
    Choose the plugin variant in two steps:

    1. Start with the platform you are actually running.
    2. Then choose the variant that matches that platform's version and Java requirement.

    Use Bukkit when you want the broadest compatibility.
    It is the general server variant and supports Minecraft 1.16.5 or newer, on Spigot and on Paper, with Java 11 or newer.
    On a server older than Java 21 it rewrites its libraries for that Java the first time it starts, which takes a little longer once.

    Use Paper when you are specifically on modern Paper or Folia and want the Paper-targeted variant.
    It is meant for newer Paper APIs, so it can be more stable and performant on supported modern setups.
    The Paper build targets Minecraft 1.20.6 or newer and Java 21 or newer; on older Paper servers use Bukkit.

    Use Velocity when Socialismus should run on a Velocity proxy.
    The Velocity build targets Velocity 4.x and Java 25 or newer.

    If you are unsure, the safe starting rule is simple:

    - Bukkit for normal server setups that need the broadest compatibility
    - Paper for Paper or Folia setups on 1.20.6+ with Java 21+
    - Velocity for proxy setups on Velocity 4.x with Java 25+
  </Accordion>
</Accordions>
