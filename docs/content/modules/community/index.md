Community modules are Socialismus modules made by the community and not maintained by Socialismus developers.
They extend Socialismus through the Socialismus module system.

This page is the routing point for unofficial and community-maintained Socialismus modules.

## Add a module

If you want a community module to be listed here, request it through one of these channels:

- [Discord](https://discord.arcadeya.com)
- [GitHub Issues or Pull Requests](https://github.com/whereareiam/Socialismus)

Community modules can eventually be listed here as internal docs pages, external documentation links, or both.
