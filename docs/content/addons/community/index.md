Community addons are plugins made by the community and not maintained by Socialismus developers.
They extend Socialismus without being loaded as modules through Socialismus itself.

This page is the routing point for unofficial and community-maintained Socialismus addons.

## Add an addon

If you want a community addon to be listed here, request it through one of these channels:

- [Discord](https://discord.arcadeya.com)
- [GitHub Issues or Pull Requests](https://github.com/whereareiam/Socialismus)

Community addons can eventually be listed here as internal docs pages, external documentation links, or both.
