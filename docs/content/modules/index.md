Modules are Socialismus extensions that are loaded through the Socialismus module system.

Socialismus has two module groups:

- official modules maintained by Socialismus developers
- community modules made by the community and not maintained by Socialismus developers

Modules can add features such as bubbles, announcements, private messaging, moderation, synchronization, or other social systems.
Review them carefully before you install them, especially when they change runtime behavior across your network.

## Module discovery

Use these pages to discover Socialismus modules:

- [Official modules](./official/index.md)
- [Community modules](./community/index.md)

Some modules may be documented directly in this docs site.
Others may link out to separate documentation maintained elsewhere.
