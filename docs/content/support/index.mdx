For support with Socialismus, use one of these channels:

- [Discord](https://discord.arcadeya.com) is the recommended option for normal support, setup questions, and faster back-and-forth troubleshooting.
- [GitHub issues and pull requests](https://github.com/whereareiam/Socialismus) are a good option for bug reports, feature requests, and changes that should stay visible and tracked.

## Response expectations

Critical fixes are usually handled quickly.
If an issue could be exploited or could seriously affect running servers, it is better to report it directly to the developers instead of posting full public details immediately.

Normal fixes, improvements, and lower-priority bugs are usually prioritized lower and may be handled over a longer period rather than immediately.
